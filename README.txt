QATRA — как вносить изменения

ОТКРЫТЬ САЙТ: дважды кликните index.html (нужен интернет: Tailwind и шрифт грузятся с CDN).

ФОТО ТОВАРОВ  -> папка images/products/
  Положите файлы hoodie.jpg, tee.jpg, jacket.jpg, pants.jpg (формат 4:5, например 1200x1500).
  Пока фото нет, показываются схематичные силуэты. Добавили фото — они подставятся сами.
  Новые товары: js/main.js, список P (название, описание, цена, имя файла).

СКАНЫ ДОКУМЕНТОВ  -> папка images/docs/
  doc-1.jpg ... doc-6.jpg по порядку списка D в js/main.js.
  Если скана нет, в окне показывается образец. Данные образцов (фонд, дата, сумма) правятся в списке D.

ЛОГОТИПЫ -> images/logo-mark.png (знак, шапка и hero), images/logo-full.png (со словом, футер и документы).
  Заменяйте файлы с теми же именами.

ТЕКСТЫ, ТЕЛЕФОН, ССЫЛКИ СОЦСЕТЕЙ -> index.html
ЦВЕТА, ЛИНИИ, КНОПКИ -> css/style.css
СУММА ПЕРЕВЕДЕНО -> index.html, атрибут data-to у элемента id="total"
